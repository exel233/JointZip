# JointZip 完整约束与 correction 消融协议（2026-10-17）

本轮只补充用户批准的两类消融，保留已经完成的所有版本。生产结果单独保存为 `vldb_framework_ablation_20261017_v1`，不修改旧实验、论文或 Overleaf。

## 1. 数据、后端与对照

采用当前六个固定后端配置：SZ3、ZFP、SPERR-1D（SPECK1D_FLT）、Serf-XOR、Serf-QT、SZ2016。后端二进制、输入、标准化、窗口、阈值、基础模型、种子、批次与之前两轮保持一致。Serf 两种模式不是两种独立算法；SZ2016 是历史版本。

固定172个输入：142条预测序列、6个UCR数据集、24个NASA文件。预测使用原VAL/TEST划分和strict/medium/loose三档；UCR使用原stress档。每个后端/臂930组配置。共同Raw只计一次。

| 臂 | 参数生成、修复和最终验收中的约束 | 用途 |
|---|---|---|
| E | 逐点误差 | 框架内部的误差约束基线 |
| ER | 误差、原序列与重建序列Pearson | 测量加入R的影响 |
| EA | 误差、原序列和重建序列的ACF差 | 测量加入A的影响 |
| ERA | 三者同时 | 直接复用10月15/16日完整结果 |
| ERA_no_correction | 同ERA验收，关闭修复 | 在固定候选集合上测量correction作用 |

E不是原生压缩器单次epsilon调用：它仍保留本框架的搜索、精确候选、修复接口与完整封装，只关闭R/A。因此旧native不能冒充本轮E臂。历史组合后端的E/ER/EA结果也不能移植为当前固定后端结果。

R为源与重建窗口Pearson；A为lags 1..16的切片Pearson ACF最大绝对差。阈值strict=(0.1,0.999,0.01)、medium=(0.25,0.995,0.02)、loose=(0.5,0.99,0.05)、UCR stress=(1,0.99,0.05)。关闭项在锚点和修复接口传-1；外层仍保存全部ERA指标，并独立报告启用约束的通过情况。

## 2. 不改变的搜索与修复

SZ3/ZFP/SPERR-1D/SZ2016保持最多22个候选、初始12个、divisor512；Serf保持8/5/64。窗口标量锚点来自启用的Pearson/ACF公式，随后使用原有按字节反馈的细化。E中关闭两种统计约束，锚点自然为epsilon。没有旧网格兜底，也不扩大搜索预算。

correction继续使用原始posthoc greedy、legacy优化器、原值和7/15/31/63/127目标、格式0–6。精确Zstd level3窗口候选保留。E臂的原生候选已通过严格cap≤epsilon检验，不需要数值修复；旧外部repair接口拒绝同时关闭R/A，因此新消融适配层跳过这一步空操作，保持候选生成、误差检查和择优不变。公式只指导候选，不宣称压缩前保证非线性ACF。

## 3. correction消融的固定候选池

每个窗口读取已完成ERA的`metadata.windows[].candidates`，按原顺序固定所有有损cap和phase，包括映射到相同ZFP有效精度的逻辑请求。无修复组不重新反馈字节改变轨迹。

无修复组要求原生重建同时满足原来的`max_error <= cap`条件和完整ERA约束，未达标候选排除。加入相同精确候选，再按原`base+repair bytes`最小、同字节优先较大cap的规则选择。其repair始终为空。选择后仍完整封装、独立解码、验收。

完整ERA侧直接复用原文件，不能重跑。原生候选缓存优先导入旧ERA赢家、旧native赢家；没有持久化的未选中候选只补算原生码流。缓存按实际后端身份、原始数据、长度、有效参数绑定，不把修复后的值当原生重建。相同原生候选可跨臂复用。恢复时保留已提交配置与窗口checkpoint。

这个比较隔离的是**条件于完整框架已生成候选池的修复作用**，不是自适应无修复算法的全局最优。无修复组可能更多使用无损，因此下游分数可能更好。主要观察修复是否减少无损回退、降低满足ERA时的完整存储成本。

## 4. 覆盖与复用

完整四臂为22320组配置；增加无修复臂后27900组。其中ERA5580组和对应43596条消费者记录直接复用。共同Raw2482条。完整消费者名册为220462条，包含VAL、种子和核验缓存，不能称为独立样本或全部新模型调用。

继续使用冻结的Raw训练权重：预测Ridge、DLinear、PatchTST三种子、Chronos2、ChronosBoltSmall、TimesFM3；UCR 1NN、Logistic、ResNet v1/v2三种子及相应检索；NASA Ridge、KNN、LSTM三种子。实际模型输入与已有记录逐位相同且依赖、预处理、批次、运行环境一致时复用，不重新训练或推理。全部预测VAL阶段先于TEST阶段。

JZF1/JZP1格式不变，CR包括normalizer、channel、shape、真实长度、原生码流和修复。NASA的true_length已经是TEST后缀长度，不二次减train_end。不同臂完整文件重新计费，不移植旧容器CR。
