# JointZip 多后端完整实验与搜索密度验证

日期：2026-10-15。运行：`vldb_framework_full_20261015_v1`。

## 目的与预先固定的比较

主要检验同一个压缩器在加入 JointZip 前后的统计保留和下游表现。固定 SZ3、ZFP、SPERR、Serf-XOR、Serf-QT 五个后端，分别运行 native 与 JointZip。不得用某个后端的原生结果对比另一个后端的框架结果后声称这是同后端收益。

SPERR 使用官方 SPECK1D_FLT，与历史独立 SPERR 对照保持一致；它与原来组合压缩器内部使用的二维模式有区别。Serf 两个模式分别列出，不能混称两个不同算法。

native 使用给定 epsilon 做一次原生压缩，不修复统计指标。JointZip 保持已完成小实验中的公式指导策略：依据 Pearson 几何界和 ACF 敏感性形成每窗口标量参数锚点，允许在 epsilon 内探索；按实际基底与修复字节择优。SZ3/ZFP/SPERR 最多 22 次有损参数尝试（初始 12 次），Serf 两模式各 8 次（初始 5 次），另含共同的精确候选。公式锚点不是非线性 ACF 的预先确定性保证；最终解码、修复及验收保证启用约束。

correction 维持原始版本：posthoc greedy、legacy optimizer、原值和分母 7/15/31/63/127 的目标、格式 0–6。不得加入后来代价较大的复杂编码。

## 数据和条件

沿用全部 172 个输入，不因先前效果挑选：142 条预测序列（ETTm1、ETTm2、ElecDem、Weather、Wind 和 Solar137），6 个 UCR 数据集，24 个 NASA 文件。每种方法共 930 条压缩配置：预测 852（VAL/TEST ×三档），UCR 6（完整 TEST，既有 stress 档），NASA 72（三档）。10 种方法共 9,300 配置。

| 档位 | epsilon | Pearson 下限 | ACF 最大差 |
|---|---:|---:|---:|
| strict | 0.1 | 0.999 | 0.01 |
| medium | 0.25 | 0.995 | 0.02 |
| loose | 0.5 | 0.99 | 0.05 |
| UCR stress | 1.0 | 0.99 | 0.05 |

保护窗口及预处理保持原协议：预测压缩128点、模型使用最后96点、预测24点；UCR整条测试序列；NASA128点块并保存真实尾部长度。数值均为训练数据统计量标准化后的 float32。Pearson 指原始与重建窗口的相关系数；ACF 为各自滞后切片 Pearson 在1–16 lag上的最大差。

## 复用和计费

SZ3、ZFP、SPERR-1D、Serf-XOR 已有 3,720 条 native 配置可提取原有原生 payload；不得重新调用压缩器。小实验仅在源数据、参数、后端、公式政策和候选数一致时复用完整窗口搜索，UCR32条查询不得当成完整 TEST。Serf-QT native 和未完成的框架条件新计算。已完成窗口保存检查点，恢复不重复搜索。

所有新比较使用同一完整 JZF1 容器，计入通道名、归一化参数、形状、真实数据长度、JZP1 基底及修复。重新封装后独立解码并核对重建。CR 的分子为实际未压缩 float32 字节，NASA 不计填充；分母为完整文件。不得直接沿用旧容器的 CR 或把复用耗时当编码速度。

## 下游

沿用固定训练模型及划分：预测 Ridge、DLinear、PatchTST（三种子）、Chronos2、Chronos-Bolt-small、TimesFM3；分类1NN、Logistic、ResNetv1/v2（三种子）；形状及深度嵌入检索；NASA Ridge、KNN、LSTM（三种子）和原 TSB 指标。保持原模型、标准化、批大小和阈值，不重新训练。相同实际输入且模型/运行环境一致，Raw复验通过后复用旧预测，否则重新推理。预计 75,142 条消费者记录包含 Raw、VAL、种子和复用，不是独立样本数。

先完成全部预测 VAL 再跑 TEST。主结果为预定阈值的成对比较；不得根据新 TEST 改阈值或挑选压缩策略。宏平均按数据集/来源优先，保留下降及约束违例，不预设框架提高每个任务分数。

## 搜索密度消融

这与主实验分开，不改变主实验的已定参数政策。固定6个预测数据源中各自第1条序列的前4个 VAL 窗口，strict/loose 两档，SZ3/ZFP 两后端。比较 formula 与 noformula 在22/44/88次候选预算下的结果，共144条件。保持初始12点不变，只延长同一细化轨迹；记录真实不同参数数、ZFP有效精度数、候选调用和修复开销。

noformula 不读取源数据的 Pearson/ACF 敏感性来生成锚点，使用固定相对区间的几何中点，其余细化、修复、最终验收完全一致。它仍验收 Pearson/ACF，因此不是“完全不控制统计指标”的对照。跨策略或预算只可复用完全相同请求的候选计算，不能把另一个策略的未提出候选反馈给当前策略。

密度结果报告完整CR、最终约束与冻结模型VAL表现；缓存后增量耗时不得当作独立速度排名。更密搜索可能改善内层基底加修复成本，但外层压缩文件的排序及下游分数不保证单调。不得凭局部结果直接切换整个主实验。
